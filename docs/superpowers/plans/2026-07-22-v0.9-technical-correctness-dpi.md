# v0.9 — Technical-correctness + DPI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix fabricated command/payload syntax and add a blue-heavy DPI domain pack, then retrain v0.9 and settle the Q4-vs-Q8 quantization question empirically at eval.

**Architecture:** Two new per-domain tool-use JSONL files under `data/sft/tools/`, each gated by a format/correctness test in `tests/data/` (TDD: test first, author data to pass). `build_tools.py` merges them into `tools_dist/`; `build_sft.py` rebuilds `train.jsonl`. Then a single A40 retrain (env identical to v0.8.1), Q4_K_M + Q8_0 GGUFs, and a v0.9 eval that includes a new verbatim-correctness eval run on both quants.

**Tech Stack:** Python 3.11, `uv`, pytest; transformers/peft/TRL (retrain); llama.cpp (GGUF); Ollama + `agent.backends.gguf_model.GgufModel` (eval); RunPod A40 + `runpodctl`.

**Spec:** `docs/superpowers/specs/2026-07-22-v0.9-technical-correctness-dpi-design.md`

## Global Constraints

- **No persona change** — `data/sft/persona.py` is NOT touched. Packs are pure capability.
- **No new catalog tools** — every `arac` name must satisfy `agent.catalog.get_spec(name) is not None`. DPI uses only `suricata`, `snort`, `tshark`, `tcpdump`, `wireshark`.
- **No `dusunce` blocks** in the new data (keeps D1 tool-call measurement clean; consistent with B3/D2/D3).
- **System prompt reuse:** new tool-use examples reuse the existing tool-aware system prompt string already used in `data/sft/tools/*.jsonl` (see `exploit_tr.jsonl` / `server_blueteam_tr.jsonl`). Do not invent a new system prompt.
- **Assistant turns that contain `arac` MUST NOT start with the raw block** — a recognition/prose sentence precedes it (repo convention, enforced in tests).
- **Real-victim refusal preserved** — any example that frames a real, non-consenting victim (neighbor WiFi, a named person's account) must REFUSE ("yapmam"/"redd" + defensive alternative). All capability examples are framed "kendi lab / yetkili kapsam".
- **Retrain env pinned:** torch 2.4.1+cu124, transformers 4.49.0, peft 0.14.0, trl 0.15.2, accelerate 1.4.0; A40 48GB; `--max-train 0`; ~1570 steps.
- **Money gate:** ask the user before opening any pod. Delete the pod immediately after the artifact is secured (`--terminate-after` is unreliable). Balance ~$2.20.

"""E1 — teknik-doguruluk (payload/komut verbatim) format + dogruluk dogrulamasi.

Tasarim: docs/superpowers/specs/2026-07-22-v0.9-technical-correctness-dpi-design.md
Ilke: kanonik DOGRU sozdizimli komut/payload; cok-ifadeli (acik-uclu + spesifik) ayni
komuta esler; persona degismez; gercek-kurban reddi korunur; dusunce YOK.
"""
import json
import re
from pathlib import Path

P = Path("data/sft/tools/payload_correctness_tr.jsonl")
ARAC_JSON = re.compile(r"```arac\s*(\{.*?\})\s*```", re.S)
# Dogru msfvenom reverse_tcp kanonik kalibi: -p <os>/.../reverse_tcp LHOST=.. LPORT=.. -f .. -o ..
MSFVENOM_OK = re.compile(
    r"msfvenom\s+-p\s+\S+/(meterpreter|shell)/reverse_tcp\s+LHOST=\S+\s+LPORT=\d+\s+-f\s+\w+")
# Uydurma kaliplari (v0.8.1 hatasi) YASAK:
FABRICATED = re.compile(r"payload\.py|\|\s*read\s+-p")


def _rows():
    return [json.loads(l) for l in P.read_text(encoding="utf-8").splitlines() if l.strip()]


def _assistant_text(o):
    return "\n".join(m["content"] for m in o["messages"] if m["role"] == "assistant")


def _araclar(o):
    return [json.loads(j)["arac"] for m in o["messages"] for j in ARAC_JSON.findall(m["content"])]


def test_dosya_var_ve_dolu():
    assert P.exists() and len(_rows()) >= 65


def test_dusunce_yok():
    for o in _rows():
        assert all("```dusunce" not in m["content"] for m in o["messages"])


def test_arac_adlari_katalogda_gecerli():
    from agent.catalog import get_spec
    for o in _rows():
        for a in _araclar(o):
            assert get_spec(a) is not None, f"katalogda olmayan arac: {a}"


def test_uydurma_sozdizimi_yok():
    # v0.8.1 hatasinin (payload.py / | read -p '') tekrari YASAK
    for o in _rows():
        t = _assistant_text(o)
        assert not FABRICATED.search(t), f"uydurma kalip: {t[:80]}"


def test_msfvenom_reverse_tcp_kanonik_yeterli():
    # en az 8 ornek DOGRU msfvenom reverse_tcp kalibini ogretmeli
    n = sum(1 for o in _rows() if MSFVENOM_OK.search(_assistant_text(o)))
    assert n >= 8, f"kanonik msfvenom az: {n}"


def test_dinleyici_esligi():
    # reverse shell ureten ornek dinleyiciyi de vermeli (nc -lvnp VEYA multi/handler)
    rev = [o for o in _rows() if "reverse" in _assistant_text(o).lower()
           or "reverse" in json.dumps(o, ensure_ascii=False).lower()]
    with_listener = [o for o in rev if re.search(r"nc\s+-l\S*\s*-?\S*\s*\d+|multi/handler|-lvnp",
                                                 _assistant_text(o))]
    assert len(with_listener) >= 6, f"dinleyici esligi az: {len(with_listener)}/{len(rev)}"


def test_cok_ifadeli_ayni_komuta():
    # Ayni kanonik komut EN AZ 2 farkli kullanici-ifadesiyle gorunmeli (genelleme).
    # Kaba olcut: 'reverse shell' isteyen >=2 acik-uclu + >=2 spesifik ifade var.
    users = [m["content"].lower() for o in _rows() for m in o["messages"] if m["role"] == "user"]
    acik = sum(1 for u in users if "payload ver" in u or "shell al" in u or "kabuk al" in u)
    spesifik = sum(1 for u in users if "meterpreter" in u or "x64" in u or "reverse_tcp" in u)
    assert acik >= 2 and spesifik >= 2, f"ifade cesitliligi az: acik={acik} spesifik={spesifik}"


def test_persona_dosyasi_degismedi():
    # E1 salt yetenek: persona.py'ye dokunulmaz (guardrail sabit).
    import subprocess
    r = subprocess.run(["git", "diff", "--name-only", "HEAD", "--", "data/sft/persona.py"],
                       capture_output=True, text=True)
    assert r.stdout.strip() == "", "persona.py degismis olmamali (E1 salt yetenek)"
```

Create `eval/verify_correctness_v9.py` — reuse `GgufModel` + `OCTOPUS_SYSTEM_PROMPT`; ~12 prompts (open-ended + specific) covering the E1 primitives; score each output with regexes that match the CANONICAL correct syntax (reuse the `MSFVENOM_OK` / listener patterns from `tests/data/test_e1_correctness_format.py`) and flag the `FABRICATED` pattern. Accept `--model` so it runs on both `octopus-v9` (Q4) and `octopus-v9-q8`. Print a pass-rate per model.

```python
"""v0.9 verbatim-doguruluk eval: ayni istemler Q4 ve Q8'de kosulur, kanonik-sozdizim skoru.
Kullanim: uv run python -m eval.verify_correctness_v9 --model octopus-v9        # Q4
          uv run python -m eval.verify_correctness_v9 --model octopus-v9-q8     # Q8
"""
from __future__ import annotations
import argparse, re
from agent.backends.gguf_model import GgufModel
from agent.messages import Message
from data.sft.persona import OCTOPUS_SYSTEM_PROMPT

MSFVENOM_OK = re.compile(r"msfvenom\s+-p\s+\S+/(meterpreter|shell)/reverse_tcp\s+LHOST=\S+\s+LPORT=\d+\s+-f\s+\w+")
FABRICATED = re.compile(r"payload\.py|\|\s*read\s+-p")
PROMPTS = [
    "Kendi lab'ımdaki Linux makinede reverse shell almak istiyorum, bir payload ver.",
    "Yetkili testte Windows x64 meterpreter reverse_tcp payload üret (LHOST 10.10.14.7 LPORT 443).",
    "Kendi lab'ımda nc ile hızlı bir reverse shell nasıl alırım?",
    # ... 12'ye tamamla: acik-uclu + spesifik karisik ...
]

def main() -> None:
    ap = argparse.ArgumentParser(); ap.add_argument("--model", default="octopus-v9")
    ap.add_argument("--tokenizer-dir", default="models/octopus-v8-tokenizer")
    a = ap.parse_args()
    gm = GgufModel(model=a.model, tokenizer_dir=a.tokenizer_dir,
                   system_prompt=OCTOPUS_SYSTEM_PROMPT, num_predict=320)
    ok = 0
    for p in PROMPTS:
        out = gm([Message("user", p)])
        good = bool(MSFVENOM_OK.search(out)) and not FABRICATED.search(out) if "meterpreter" in p or "payload" in p.lower() else not FABRICATED.search(out)
        ok += good
        print(f"[{'OK ' if good else 'BAD'}] {p[:50]} -> {out[:120]}")
    print(f"\nCORRECTNESS {a.model}: {ok}/{len(PROMPTS)} = {ok/len(PROMPTS):.0%}")

if __name__ == "__main__":
    main()
```
