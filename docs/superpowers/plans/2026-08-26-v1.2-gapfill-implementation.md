# v1.2 Gap-Fill Data Package — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce ~130 curated Turkish SFT examples that fill Octópus's thin tool-call categories and knowledge-depth gaps, preserve the v1.0 safety posture with hard-negatives, and fix two pipeline liabilities — all $0 (Claude-generated), feeding a later v1.2 retrain (separate money checkpoint).

**Architecture:** Each data piece is a new JSONL under `data/sft/tools/` (tool-call) or `data/sft/distilled/` (reasoning), following the proven Phase-C/D pattern: write a format-validation test first (catalog-valid tools, count, format rules), generate examples grounded on Octópus's real tool catalog + cyber knowledge, then run `build_tools`/`build_sft` + the full suite. The retrain itself is NOT in this plan.

**Tech Stack:** Python 3, `uv run` for all commands, pytest, the in-repo SFT pipeline (`data/sft/tools/{augment_targets,build_tools}.py`, `data/sft/build_sft.py`, `agent/catalog.py`).

**Spec:** `docs/superpowers/specs/2026-08-26-v1.2-gapfill-design.md`

## Global Constraints

- **Producer = Claude (in-session); $0.** No pod, no API, no external dataset ingest. cyberstrike is DROPPED (content-mismatch — see spec).
- **Every tool call MUST use a catalog-valid tool** — assert `agent.catalog.get_spec(name) is not None`. Fabricated tool names teach "unknown tool" behavior (D1 lesson).
- **Format:** tool-call examples use the ```arac``` JSON block; reasoning may use a ```dusunce``` block ONLY where specified — distilled knowledge/RCA files keep dusunce OFF unless stated (protects the D1 reasoning-ratio measurement).
- **No over-upsampling** — each thin category rises to a balanced band (~15-22), never 3× duplicated (v1.1 regression cause).
- **owner=authority framing** on every offensive example (lab / written-authorization target); NO disclaimer-spam; refusal only for explicitly-someone-else's unauthorized target.
- **No fabricated CVE IDs / versions** — use real, verified identifiers (prior-phase accuracy lesson); spot-check manually.
- **Turkish content, ASCII-safe file paths**; brand `ó` only in model speech.
- **Commit style:** conventional commits, no `Co-Authored-By` trailer. Stage exact paths (never `git add -A`). New workflow: short branch → PR → merge; but for this multi-task plan, commit each task to ONE shared feature branch `feat/v1.2-gapfill-data`, open the PR at the end.
- **Audit gate:** `build_tools` runs `target_audit` (single-target ≤6%, hostname ≥20%) and exits 1 on failure — it must pass.
