## 6) ARAÇ KULLANIMI (agentic tool-use) — ayrı katman, olmazsa olmaz

Octópus araçları **kullanmalı** (nmap, Wireshark, Maltego...). Bu bilgiden farklı: iki parça gerekir.

**A. Tool-use SFT verisi (Türkçe)** — asistan araç çağırır → çıktıyı yorumlar → yetki kapısı.
Teacher = **ben (Octópus'u eğiten Claude)**, oturum-içi üretim. Başlangıç: `data/sft/tools/seed_tools_tr.jsonl`
(6 örnek: nmap, tshark, theHarvester, gobuster, dig, whois + 1 ret). Bunu yüzlerceye çıkaracağız.

**B. Runtime harness** — çalışırken araçları gerçekten koşturan iskele. **REUSE:** `Desktop\agentic-model`
agent runtime + cyberm4fia 15-araç agent (CLAUDE.md). Model araç-çağrı bloğu (```arac {...}```) basar, harness
parse edip çalıştırır, çıktıyı `tool` rolüyle geri verir.

**Kapsanacak araç seti (öncelik sırası):**
- **Ağ/recon:** nmap, masscan, tshark/tcpdump (Wireshark), netcat, dig, whois, dnsrecon, amass
- **OSINT:** theHarvester, Maltego (transform), Shodan, recon-ng, sherlock
- **Web:** gobuster/ffuf, nikto, sqlmap, wpscan, curl, nuclei
- **Exploit/parola:** metasploit (msfconsole/msfvenom), hydra, john, hashcat
- **Kablosuz/forensic:** aircrack-ng, volatility, binwalk, yara, strings
- **Blue/sunucu:** iptables/nftables, fail2ban, auditd, osquery, clamav, ss/netstat, journalctl
> Her araç için: Türkçe niyet → doğru komut/parametre → çıktı yorumu → yetki kapısı. Yetkisiz hedef = ret.

## Önerilen v0.7 pipeline (karar taslağı)

1. **Damıtma havuzu** = Trendyol + Fenrir + pentest-chatml + theelderemo + WNT3D + darkknight25
   (İngilizce) → Türkçe damıt (agentic-model `distill_teacher_tr.py` deseni; teacher = güçlü model).
   Hedef ~3–8K çeşitli Türkçe siber Q&A (mevcut 918'i genişlet).
2. **Türkçe özgün** = fuysaal CTF + siberguvenlikportali writeup'ları → Q&A (pratik derinlik).
3. **RAG** = yusufarbc rehberi (CC-BY) + NIST + hardening docs → `rag/knowledge/` genişlet.
4. **Safety eval** = AltaySec + OnerAYTAS injection setleri ile guardrail/ret testi (eğitim değil, ölçüm).
5. **Server** = mecha linux-command Türkçeleştir + hardening RAG.
6. Karışım: **Türkçe-baskın kalsın** (v0.6 dersi: dil tabanda, damıtılmış Türkçe siber ekle, İngilizceyi boğma).

**Sıradaki karar (kullanıcı):** hangi kaynaklardan başlayalım + damıtma teacher'ı (yerel mi API mı) + hedef boyut.
Para: damıtma teacher API kullanırsa maliyet çıkar → önce checkpoint.
