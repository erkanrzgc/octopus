## 1) Ağ keşfi & port tarama
| Araç | Amaç (TR) | Tipik komut |
|---|---|---|
| **nmap** | Port/servis/OS tespiti, NSE betikleri | `nmap -sS -sV -sC -O -T4 -p- 10.10.10.5` |
| **rustscan** | Ultra-hızlı port tarama (65k port ~3sn), nmap'e pipe | `rustscan -a 10.10.10.5 -- -sV -sC` |
| **masscan** | İnternet-ölçekli çok hızlı tarama | `masscan 10.0.0.0/8 -p80,443 --rate 10000` |
| **netdiscover** | ARP ile canlı host keşfi (DHCP'siz ağ) | `netdiscover -r 192.168.1.0/24` |
| **arp-scan** | Yerel ağ ARP taraması | `arp-scan --localnet` |
| **fping / ping sweep** | Toplu canlılık kontrolü | `fping -a -g 192.168.1.0/24 2>/dev/null` |

## Octópus entegrasyonu (nasıl SFT'ye dönüşür)
Her araç için Türkçe örnek üretilecek (teacher = ben): **kullanıcı niyeti → akıl yürütme → ```arac``` çağrısı →
çıktı yorumu → sonraki adım / yetki kapısı**. Başlangıç: `data/sft/tools/seed_tools_tr.jsonl` (nmap, tshark,
theHarvester, gobuster, dig, whois). Hedef: yukarıdaki ~90 aracın her biri için 3-10 çeşitli senaryo.
Runtime harness (araçları gerçekten koşturma) → `Desktop\agentic-model`'den port.
