- **Date:** 2026-08-17
- **Branch:** feat/b2-assistant-sft-data
- **Verdict:** ❌ **DO NOT PROMOTE.** v1.0 (`octopus-v10`) remains the production default.

## What v1.1 was
v1.0 + **24 new server-RCA examples** (session-drop + disk-freeze archetypes), upsampled ~3×
(commit `335cd6b`). Goal: raise RCA *evidence-before-conclusion* — call a ```arac``` to gather
evidence **before** asserting a root cause — especially the two held-out cases v1.0 still guessed
on (session-drop = case 4, disk-freeze = case 5). Target: **RCA ≥ 4/5**, Pareto ≥ v10 elsewhere.

## Method (why this eval is trustworthy)
- Home downlink ~0.3 MB/s → local GGUF pull ≈ 5 h; user approved a ~$0.5 **GPU-pod** eval instead.
- **Paired:** BOTH v10 and v11 pulled from HF and run on the **same A6000 pod**, identical settings
  (temp = 0; rca `num_predict=640`; correctness `num_predict=512`), same Turkish-Gemma tokenizer.
  This removes environment confounds.
- **Validity anchor:** pod-v10 reproduced its *local* baseline exactly — rca 3/5,
  toolcall emit 96 / valid 96 / katalog 88 / doğru-araç 75, E1 83 %. So the pod measures faithfully
  and v11's deltas are **real model behavior**, not environment.
- Two harness bugs caught + fixed mid-run: (1) missing `zstd` (ollama installer),
  (2) missing `jinja2` (`apply_chat_template`) — the latter zeroed the first sweep; after
  `pip install jinja2` the re-run produced valid output (sanity gen: *"Ben Octópus 🐙 …"*).

## Truncation ruled out (the documented trap)
Project history: a low `num_predict` truncates the trailing ```arac``` → false "belirsiz".
Tested v11 RCA at **np=640 AND np=1024 → both 2/5** (unchanged). The belirsiz replies end as
**clean prose** (disk case, np=1024: *"…yedek alıp değiştirmeyi planla"*, no ```arac``` fence,
365 chars, natural ending) — the model **chose direct advice over a tool call**; it was not cut
off. v11's RCA 2/5 is real. (Evidence: `diag_np_sweep.log`.)

## Case-level (RCA)
- **fork/EMFILE:** v10 KANIT (emits `run_cmd ps -eo state,pid,wchan…`) → **v11 belirsiz (prose). REGRESSED.**
- web-slow, nginx-restart: both KANIT.
- **session-drop** (new archetype target): both belirsiz — v11's new data did **not** fix its own target.
- **disk-freeze** (new archetype target): v10 not-KANIT (TAHMIN/prose), v11 belirsiz — not fixed.

## Verdict
v1.1 is **not Pareto ≥ v1.0**: it **regresses on RCA (the primary target) and on tool-calling**,
while holding persona and payload-correctness. The 24 narrow, ~3×-upsampled RCA examples appear to
have nudged the model toward **direct prose RCA conclusions over evidence-gathering tool calls** —
the opposite of the intent — and collaterally softened general tool selection.
**DO NOT PROMOTE. Keep v1.0 (`octopus-v10`) as default.**
