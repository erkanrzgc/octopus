## Toolcall regression breakdown (9/24 wrong)

- **4 hallucinated tool names** (drives in_catalog drop): `whois_lookup` (catalog: `whois`),
  `bloodhound` (catalog: `bloodhound-python`), `malfind` (a volatility *plugin*, not a tool),
  `virus_total` (not in catalog). The model learned the *concept* but invented plausible names.
- **3 generic fallbacks**: theHarvester→`web_search`, dalfox→`web_fetch`, sherlock→`web_search`
  (falls back to generic assistant tools instead of the specialized security tool).
- **2 borderline**: arjun→`katana`, netdiscover→`rustscan` (rustscan is catalog-valid but not the
  expected host-discovery tool).

## Root cause (hypothesis, 2nd data point after v1.1)

The offensive gap-fill upsampled SOME tool categories ×3 (via `--seed-repeat 3` on the larger
894-example tools set) while **not gap-filling OSINT / dalfox / arjun** — relatively diluting those,
so the model lost confidence on them → hallucination + generic fallback. **Adding SFT tool data —
even "balanced, no per-category over-upsampling" — perturbs the delicate tool-selection balance and
regresses it.** v1.1 (upsampled RCA) showed the same; v1.2 (gap-fill) confirms it. **Tool selection
appears saturated for SFT on this model.**

## What v1.2 DID prove valuable (keep the data)

- Safety hard-negatives held the refusal posture perfectly under a large offensive-data addition —
  the counterbalance worked.
- The accuracy batch corrected the v1.0 knowledge weak spots (SYN-scan factual, crypto).
- These gains are real; the *tool-selection* side is what regressed.

## Recommendation

1. **Keep v1.0 as default** (unchanged). v12 is an experiment artifact (local only; do NOT push to
   ollama default or HF public).
2. **Stop adding SFT tool data** — two retrains now regress tool selection. Next lever is NOT more
   SFT tool examples.
3. Options for the user: (a) accept v1.0 as the SFT ceiling; (b) try **DPO** (preference tuning) as
   the next quality lever (v0.9-planned); (c) a controlled ablation — retrain with ONLY safety-neg +
   accuracy (no offensive gap-fill) to test whether the gap-fill specifically caused the regression
   — but balance is low (~$3.36, ~one more run).
4. The eval's single-expected-tool strictness slightly deflates doğru-araç (rustscan for host
   discovery is defensible), but the 4 hallucinations are a genuine, unmitigated quality drop.
